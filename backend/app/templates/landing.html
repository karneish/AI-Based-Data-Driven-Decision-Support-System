Capabilities

Everything an academic advisor needs

Ensemble Classification

Logistic Regression, Decision Tree, Random Forest, K-Nearest Neighbors and Gradient Boosting vote together, with a data-calibrated class threshold.

Academic Stability Index

An AI-calibrated composite that blends ensemble probability with attendance and study hours into one interpretable 0–100 score.

Counterfactual Recommendations

Each action is simulated against the trained ensemble to measure its predicted probability gain, then ranked by impact.

Model Comparison

Side-by-side accuracy, precision, recall, F1, AUC and confusion matrices so you can audit every algorithm.

Machine Learning

The five-model ensemble

Every model is trained on the same 800-student training split and evaluated on a held-out 200-student test set at startup.

Logistic Regression

Interpretable probabilistic baseline — often the strongest overall performer.

Decision Tree

Transparent rule-based splits that are easy to explain to stakeholders.

Random Forest

Bagged trees that supply the global feature-importance ranking.

K-Nearest Neighbors

Distance-based classifier that captures local profile similarity.

Gradient Boosting

Histogram-boosted trees that squeeze out the last bits of accuracy.

= Ensemble

Soft-vote mean of all five model probabilities, with a confidence score based on cross-model agreement.

Methodology

How an analysis is produced

Academic Stability Index

Weights are learned from logistic-regression coefficients on the training data at startup:

ML Probability × 0.96
Attendance × 0.01
Study Hours × 0.03

Range 0–100 · higher = more stable

Pipeline

1. Inputs validated → scaled
2. Five models predict → soft-vote
3. Youden-optimal class cutoff
4. ASI composite + risk band
5. Counterfactual gain ranking
